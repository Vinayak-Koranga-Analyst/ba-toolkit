# BA Toolkit

Plain Markdown templates for the core business analysis documents, plus a short guide on when and how I use each one.

These are the documents I come back to on most projects. They're kept short on purpose: a template should prompt the right questions, not create paperwork. Copy one, delete what doesn't apply, and fill in the rest.

## Templates

| # | Template | Use it to |
|---|---|---|
| 01 | [Stakeholder register and map](templates/01-stakeholder-register.md) | List who is affected, what they care about and how to engage them |
| 02 | [RACI matrix](templates/02-raci-matrix.md) | Agree who does, owns, advises on and is told about each activity |
| 03 | [Business Requirements Document (BRD)](templates/03-brd.md) | Record the problem, scope and business requirements for sign-off |
| 04 | [Process map (as-is / to-be)](templates/04-process-map.md) | Map the current and future process in Mermaid, with a pain-point log |
| 05 | [User story and acceptance criteria](templates/05-user-story.md) | Write backlog items that a team can build and test |
| 06 | [Requirements traceability matrix (RTM)](templates/06-rtm.md) | Trace each requirement to stories, tests and sign-off |
| 07 | [UAT plan and test script](templates/07-uat-plan-and-script.md) | Plan user acceptance testing and record results |

A CSV version of the RTM is in [`templates/rtm-template.csv`](templates/rtm-template.csv), ready to open in Excel or import into a tracker.
